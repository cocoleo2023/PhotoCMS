# PhotoCMS — этап 3: дизайн-система, блог, слайдеры, эффекты

## Установка на shared-хостинг
1. Создайте пустую базу MySQL (utf8mb4) и пользователя в панели хостинга.
2. Загрузите содержимое папки в корень сайта (public_html). Нужны PHP 8.1+ (PDO MySQL, GD с WebP, mbstring, fileinfo) и Apache с mod_rewrite.
3. Откройте `https://ваш-сайт/install.php`, введите данные базы и администратора. После установки удалите `install.php`.
4. Админка: `/admin/`.

## Локальный запуск на macOS
```
brew install php mariadb && brew services start mariadb
mariadb -u root -e "CREATE DATABASE photocms CHARACTER SET utf8mb4; CREATE USER 'photocms'@'127.0.0.1' IDENTIFIED BY 'photocms'; CREATE USER 'photocms'@'localhost' IDENTIFIED BY 'photocms'; GRANT ALL ON photocms.* TO 'photocms'@'127.0.0.1'; GRANT ALL ON photocms.* TO 'photocms'@'localhost';"
cd /путь/к/photocms
php -d upload_max_filesize=64M -d post_max_size=300M -d memory_limit=1G -S localhost:8080 router.php
```
Откройте http://localhost:8080/install.php. База: сервер `127.0.0.1`, имя `photocms`, пользователь `photocms`, пароль `photocms`.
Остановить: Ctrl+C в терминале и `brew services stop mariadb`.

## Обновление с этапа 1
Загрузите новые файлы поверх старых (`config.php` и папку `uploads/` не трогайте). База обновится сама при первом открытии сайта.

## Как собрать сайт
1. **Галереи** → создайте галерею, перетащите фото.
2. **Страницы** → создайте «Главная», добавьте блоки (Обложка, Текст, Галерея, Фото и текст, Цитата, Цены, Призыв, Форма заявки, Отступ, HTML). Порядок меняется стрелками.
3. Отметьте «Сделать главной страницей», нажмите «Предпросмотр», затем опубликуйте.
4. **Настройки** → название, контакты, цвет, шрифты, вид шапки, фон.
5. **Заявки** → сообщения из формы (дублируются на email из настроек, если на хостинге работает mail()).

## Раздел «Дизайн» (с живым предпросмотром справа)
- **Палитры:** 11 готовых (в том числе светлые: «Белый воздух», «Песок», «Туман», «Шалфей», «Пудра», «Лёд», «Лаванда», «Олива») и свои цвета: фон, текст, акцент, светлая и тёмная подложки.
- **Шрифты:** 18 гарнитур со встроенной кириллицей (хранятся на вашем сайте, Google Fonts не нужен). Отдельно для заголовков, текста, цитат, акцентных подписей и меню. Начертание, размер, межбуквенное расстояние, регистр, межстрочный интервал.
- **Расстояния:** между блоками и внутри блоков (в процентах от стандарта), ширина сайта, скругления, вид кнопок.
- **Шапка:** расположение, размер названия, закрепление, прозрачная поверх обложки.
- **Эффекты:** анимации и параллакс (включить/выключить, скорость), плавное открытие страниц, плавная прокрутка.
- **Блог:** 5 вариантов (сетка, список, журнал, каскад, минимализм), 3 вида карточек, колонки, пропорции, что показывать, обложка и ширина записи.

## Блоки (редактор страницы или записи → «Оформление и анимация»)
Блоки: обложка, текст, фото, фото и текст, галерея, **слайдер**, **преимущества**, цитата, **отзывы**, **цифры со счётчиком**, цены, **вопросы и ответы** (с разметкой FAQPage), призыв, форма заявки, **бегущая строка**, **видео** (YouTube/Vimeo), **записи блога**, **разделитель**, отступ, HTML.
У любого блока: отступы, ширина, фон (цвет или **фото с параллаксом**), шрифт и **эффект заголовка** (по словам, по буквам, печатная машинка, градиент, контур, прорисовка подчёркивания), 11 эффектов появления, скорость, задержка, видимость на телефоне и компьютере.
Галереи: каскад, ровная сетка, ряды одной высоты, коллаж, слайдер, лента, колонка; обработка фото (чёрно-белое, цвет при наведении…), рамки, подписи, эффекты при наведении и появлении.

## Блог
Раздел «Блог»: записи с обложкой, анонсом, рубрикой, датой (в том числе отложенная публикация), SEO-полями и тем же редактором блоков. Адреса `/blog`, `/blog/<запись>`, `/blog/category/<рубрика>`, RSS `/feed.xml`, записи попадают в `sitemap.xml`.

## Предпросмотр
В редакторе страницы/записи и в «Дизайне» показывает несохранённые изменения (компьютер, планшет, телефон) и не трогает опубликованное. Ctrl/Cmd+S сохраняет. Анимации отключаются глобально и автоматически у посетителей с режимом «уменьшить движение».

## Структура
- `index.php` — публичный роутер; `admin/` — админка и редактор блоков
- `core/blocks.php` — каталог блоков (добавить новый блок = одна запись в `block_types()` и ветка в `render_block()`)
- `themes/air/` — тема (шрифты в `fonts/`, скрипты `fx.js` эффекты, `ui.js` слайдеры и видео). Новая тема = новая папка с layout, page, home, gallery, blog, post, 404
- `core/theme.php` — шрифты, палитры, настройки дизайна; `core/blocks*.php` — каталог и отрисовка блоков; `core/blog.php` — блог
- `uploads/` — фото (выполнение PHP запрещено)


## SEO и аналитика (раздел «SEO» в админке)

- **Аудит**: чек-лист сайта и оценка каждой страницы (заголовок, описание, дубли, картинка, объём текста, ключевая фраза).
- **В редакторе** страницы, записи и галереи: сниппет Google/Яндекс, счётчики длины, ключевая фраза, noindex, свой canonical, картинка для соцсетей.
- **Основное**: главный адрес сайта, разделитель и бренд в title, HTTPS и www (301), закрытие от индексации на время разработки, robots.txt, запрет AI-роботов, /llms.txt, коды Google / Яндекс / Bing.
- **Организация**: JSON-LD (Photographer/LocalBusiness), BlogPosting, ImageGallery, BreadcrumbList на каждой странице.
- **Аналитика**: Яндекс Метрика (клики, вебвизор), GA4, GTM, свой код, баннер согласия на cookie, автоцели (form_submit / generate_lead, click_phone, click_email, click_social). Админы и предпросмотр не считаются.
- **Редиректы и 404**: ручные и массовые 301/302, маски `/old/*`, автоматический 301 при смене адреса, журнал 404.
- **Индексация**: sitemap.xml (lastmod и фото), IndexNow (Яндекс, Bing), инструкция по запуску.

После обновления откройте любую страницу сайта: миграция БД (схема v7) выполнится сама.
